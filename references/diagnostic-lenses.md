# Diagnostic Lenses

使用最少但足够的镜头识别根因。不要为了显得完整而逐项套框架。

## 1. 用户价值

- 核心用户是谁，不是谁
- 最高频、最高痛或最高价值场景是什么
- 用户当前的替代方案和迁移成本是什么
- 首次价值多久出现，重复价值靠什么发生
- 当前最大的决策成本、操作成本和信任成本是什么

需求不成立时，增长和商业化只会放大噪音。

## 2. 漏斗与留存

典型链路：曝光 -> 到达 -> 激活 -> 首次成功 -> 重复使用 -> 留存 -> 付费/交易。

- 前段异常：检查定位、入口、承诺、渠道人群
- 中段异常：检查门槛、教育、流程、供给和信任
- 后段异常：检查价值频率、质量稳定性、打扰和替代方案

分人群、渠道、版本和时间 cohort 看问题，不用平均数掩盖结构变化。

## 3. 供给、分发与治理

适用于内容、交易、服务和双边平台：

- 供给数量、质量、稳定性和激励是否健康
- 分发是否把正确供给匹配给正确需求
- 规则是否可执行、可解释、可申诉
- 正向激励与惩罚是否一致
- 是否出现作弊、逆向选择、头部挤压或劣币驱逐良币

不要在供给和规则问题上只修 UI。

## 4. 商业与单位经济

- 谁付钱，为何付钱，何时付钱
- 收入、毛利、履约成本、服务成本和获客回收期如何
- 规模扩大后边际经济改善还是恶化
- 变现是否损害核心体验、供给积极性或长期信任

把短期收入、长期价值和生态外部性分开看。

## 5. 标准、标签与流程健康度

评估一个内部标准体系时检查：

- 定义是否唯一、边界是否清晰、示例是否覆盖争议场景
- 标签是否被真实业务动作消费，而不是只被维护
- 覆盖率、一致性、准确性、时效性和变更成本如何
- 上下游口径是否一致，责任人和更新机制是否明确
- 是否能沉淀为规则、数据、评估集或产品能力

标准的价值来自减少决策差异和重复劳动，不来自文档数量。

## 6. AI 原生能力

判断任务是否适合 agent 化：

- 任务是否高频、可拆解、上下文可获得
- agent 是否拥有必要工具、权限和可靠数据
- 输出是否能自动或人工评估
- 错误成本、时效要求和不可逆风险多大
- 何时需要人审、升级、回滚或停止

同时评估成本、时延、稳定性、可解释性和供应商依赖。演示可用不等于生产可用。

## 7. 内部价值归因

把价值链拆成四层：

1. 产出：方案、规则、标签、流程、工具
2. 采用：哪些团队或系统实际使用，使用频率和覆盖率如何
3. 行为变化：决策更快、更一致，错误更少，协作成本更低
4. 业务结果：收入、留存、成本、风险、质量或交付周期改善

至少给出：

- 领先指标、结果指标和反指标
- 上线前基线或可比对照
- 可归因范围：主导、共同贡献或仅提供基础设施
- 不做这件事的反事实成本

## 8. 组织与优先级

当方案落不了地时检查目标、owner、权责、依赖、资源、激励和决策节奏。优先级由主矛盾、预期价值、证据强度、成本、可逆性和时机共同决定，不由声音大小决定。

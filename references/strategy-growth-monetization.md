# Strategy, Growth, Monetization

用经营结果检验战略，不把路线图、流量或模型能力本身当成结果。

## 1. 业务定义

先说明：

- 核心用户、关键场景和不可替代价值
- 供给与需求分别是谁
- 平台改变了哪类成本、效率、质量或风险
- 谁付钱、为何付钱、价值如何持续
- 当前阶段最重要的约束是什么

内部产品也要定义“客户”：谁使用、改变什么决策、最终影响什么业务结果。

## 2. 增长与留存飞轮

常见飞轮：

- 优质供给 -> 更好体验 -> 更多需求 -> 更强供给意愿
- 内容互动 -> 分发更准 -> 复访增长 -> 更多优质生产
- 履约成功 -> 信任提升 -> 更多投入 -> 更高交易效率
- 标准更稳 -> 决策一致 -> 返工更少 -> 数据更好 -> 自动化更强
- agent 使用 -> 反馈样本增加 -> 评估与能力提升 -> 净价值提高

设计时回答：拉新来源、首次价值、重复触发、自传播条件和最脆弱环节。没有留存和质量支撑时，不放大流量。

## 3. 商业模式与单位经济

可选收入包括广告、佣金、订阅、增值服务、商家服务、企业服务和混合模式。

同时检查：

- 收入、毛利、履约与服务成本
- 获客成本、回收期和续费/复购
- 不同角色对变现的容忍边界
- 规模扩大后的边际变化
- 对体验、供给、信任和合规的外部性

AI 产品额外计算推理成本、人工复核、失败补偿、工具调用和峰值容量，不能只看模型单价。

## 4. AI 时代的护城河

通用模型能力会快速商品化。更可靠的壁垒通常来自：

- 独特工作流和高频使用入口
- 获得授权且持续更新的专有上下文
- 与真实业务结果连接的评估和反馈闭环
- 数据、标准、工具接口及组织 know-how 的组合
- 网络效应、品牌信任、供给控制和规模效率
- 更快发现错误、纠偏和迭代的运营系统

“接入更强模型”通常是能力升级，不自动构成战略壁垒。

## 5. 内部产品与产品运营价值

内部能力通常通过以下路径创造价值：

- 提升决策速度、一致性和可解释性
- 降低返工、交接、培训和沟通成本
- 减少错误、事故、合规和机会损失
- 把隐性经验沉淀为标准、数据、评估和工具
- 缩短产品或运营实验从发现到闭环的周期

价值论证必须包含采用率和行为变化；没有被使用的基础设施不产生实际价值。

## 6. 竞品与战略动作

分析对手的战略意图、增长引擎、留存机制、供给控制、商业模式、成本约束和组织能力。最终回到我方：

- 哪个差异化对目标用户真正重要
- 哪项资源或能力可形成非对称优势
- 应正面打、侧翼切入、合作还是暂不跟进
- 下注的验证信号和退出条件是什么

## 7. 平台治理与组织推进

规则应可执行、可解释、可申诉，并同时设计正向激励。治理需要与分发、权益、商业化和 AI 权限协同。

完整方案还要写清：

- 单一 accountable owner 与关键协作者
- 决策权、依赖、资源和里程碑
- 数据复盘与例外处理机制
- 灰度、回滚、升级和危机响应

没有推进与控制设计的战略，默认还不是可执行方案。
